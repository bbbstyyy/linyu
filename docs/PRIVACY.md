# 隐私说明

淋浴小助手是独立的非官方客户端。项目不运营账号或水控中转服务器。

## 应用处理的信息

- 手机号和手动输入的短信验证码：用于向相关服务申请登录。
- 服务返回的账号标识、学校标识、登录 token、会话和业务密钥：用于保持登录与完成水控请求。
- 账号已绑定的设备、所选设备、余额、状态和未完成操作记录：用于展示设备及避免重复控制。

这些信息直接通过 HTTPS 发送至相关服务，当前主要使用 `app.17wanxiao.com` 和 `vwater.59wanmei.com`。第三方对收到数据的处理适用其自身政策；本说明描述本应用的行为。

## 本机保存

账号与会话状态通过 Android Keystore 的 AES-GCM 密钥加密，保存在应用私有的、不参与备份的目录中。系统备份和设备迁移均关闭；不把完整服务器响应或登录凭据写入应用日志。

退出登录会清除应用保存的账号状态，但不等同于在服务端撤销所有登录。卸载会清除本机应用数据。退出或卸载前，请先在现场确认停止用水。

## 权限

| 权限类别 | 用途 |
| --- | --- |
| 网络与网络状态 | 登录、查询和水控请求 |
| 前台服务及数据同步 | 用户发起操作时短时执行并显示状态 |
| 通知 | 展示正在进行的操作；拒绝后仍可使用应用 |
| 唤醒锁 | 短时间内保持正在执行的操作 |
| 开机完成 | 支持系统恢复持久后台任务 |

不读取短信、通讯录、位置或相册，不包含广告、行为统计或自动崩溃上报 SDK。桌面小组件会显示设备和余额，旁人可能看到；是否添加由用户决定。

自动续期默认开启，可在「我的」页关闭。后台维护只处理会话和查询，不主动开关阀，也不自动发送短信。反馈问题时，请自行遮盖截图中的个人信息。
